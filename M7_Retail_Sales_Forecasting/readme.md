This project analyzes retail sales seasonality data using multiple machine learning and statistical models to determine optimal forecasting performance.
Models explored: Prophet, Random Forest, XGBoost (with hyperparameter tuning), ARIMA, SARIMA, and others.
The dataset includes key features such as `item_types` and `suppliers`, providing critical context for interpreting gaps and trends in seasonal demand patterns.
We will calculate the MSE, RMSE score to determine the best model using the entire dataset
